How-to guides for popular PDF tasks

Follow these short instructions to merge, compress, convert, protect, edit, or sign a PDF. Every step happens locally in your browser.

How to merge PDF files

  1. Open the Merge PDF tool.
  2. Choose two or more PDF files from your device.
  3. Arrange the files in the order you want them to appear.
  4. Review the page previews for the final document.
  5. Select Merge & download to save one combined PDF.
Merge PDF files →

How to compress a PDF

  1. Open the Compress PDF tool.
  2. Choose the PDF file you want to make smaller.
  3. Select the balance you prefer between image quality and file size.
  4. Start compression and wait while the browser rebuilds the pages.
  5. Download the smaller PDF to your device.
Compress a PDF →

How to convert JPG to PDF

  1. Open the JPG to PDF tool.
  2. Choose one or more JPG or PNG images.
  3. Arrange the images in the correct page order.
  4. Choose the page margin for the finished document.
  5. Select Create PDF and download the result.
Convert JPG to PDF →

How to protect a PDF with a password

  1. Open the Protect PDF tool.
  2. Choose the PDF file you want to secure.
  3. Enter a strong password that you can remember.
  4. Confirm the same password and protect the document.
  5. Download the password-protected PDF before sharing it.
Password protect a PDF →

How to edit a PDF online

  1. Open the Edit PDF tool and choose a PDF.
  2. Add a text box or select an item already placed on the page.
  3. Change fonts, text size, formatting, colors, or highlights.
  4. Add shapes, arrows, checkboxes, or form fields when needed.
  5. Select Apply edits & download to save the edited PDF.
Edit a PDF →

How to sign a PDF

  1. Open the Sign PDF tool and choose your document.
  2. Draw a signature, type your name, or upload a signature image.
  3. Place the signature on the correct PDF page.
  4. Resize and position it so it fits the signature line.
  5. Select Sign & download to save the signed PDF.

Frequently asked questions

Clear answers about pricing, privacy, supported tools, and using this PDF toolkit on your device.

Are these PDF tools free to use?

Yes. Every tool on this page is free to use, with no account or sign-up required.

Are my files uploaded to a server?

No. Your files are processed locally in your browser and are not uploaded to us or stored on a remote server.

Which PDF tools are available?

You can merge, split, compress, rotate, extract, edit, sign, watermark, number, protect and unlock PDFs; convert PDFs, Word files, Excel workbooks, PowerPoint files and images; and remove or crop image backgrounds.

Do the PDF tools work on mobile devices?

Yes. The tools are responsive and work in modern mobile, tablet and desktop browsers. Larger documents may process faster on devices with more memory.

Do I need to install software or create an account?

No. Open a tool in your browser, choose your file, adjust the available settings and download the result.

What happens to my files after I finish?

Files exist only in the current browser workspace. They disappear when you refresh or close the page, and the finished file downloads directly to your device.
